# Tale of Immortal: Tradução PT-BR

Tradução para o português do Brasil de **Tale of Immortal** (鬼谷八荒), feita como mod pelo sistema oficial de mods do jogo.

Interface, itens, habilidades, destinos, missões, diálogos de história e o registro de vida dos NPCs.

## Instalação

1. Baixe o `.zip` da versão mais recente na aba [**Releases**](https://github.com/ViktorHSO/TraduTale-PTBR/releases).
2. Extraia a pasta `Mod_a21Qjs` dentro de `ModExportData`, na pasta de instalação do jogo:
   ```
   <pasta do jogo>\ModExportData\Mod_a21Qjs\
   ```
3. Abra o jogo e ative o mod em **Mods Locais**.
4. Deixe o idioma do jogo em **English**. O mod substitui os textos em inglês pelo português.
5. Reinicie o jogo.

## Observações

- Alguns textos ficam fora das tabelas do jogo, dentro do próprio código ou de certos eventos. Esses podem continuar em inglês.
- Se você usa outro mod que altera textos, ele pode sobrescrever parte da tradução, conforme a ordem de carregamento.
- Achou um erro de tradução? Abra uma [Issue](https://github.com/ViktorHSO/TraduTale-PTBR/issues) dizendo onde o texto aparece (ou mande um print).

## Arquivos deste repositório

| Arquivo | Conteúdo |
|---|---|
| `ModExcel/LocalText.json` | Interface, itens, habilidades, diálogos de história, missões e destinos |
| `ModExcel/RoleLogLocal.json` | Registro de vida, falas de NPC, eventos e histórias de região/DLC |
| `ModExcel/BattleSkillPrefixName.json` | Partes dos nomes de técnicas gerados aleatoriamente |
| `ModExcel/ItemProps.json`, `ModExcel/TaskBase.json` | Arquivos do projeto com os valores originais do jogo (não alteram nada) |

Esses são os arquivos-fonte do projeto no editor de mods. Para jogar, use o mod exportado da aba Releases.
